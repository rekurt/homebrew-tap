# homebrew-tap

Homebrew formulae for [rekurt](https://github.com/rekurt)'s tools.

```bash
brew install rekurt/tap/git-barber
```

## Formulae

- **[git-barber](https://github.com/rekurt/git-barber)** — trims stale merged git
  branches, including GitHub-style squash and rebase merges that
  `git branch --merged` cannot see.
